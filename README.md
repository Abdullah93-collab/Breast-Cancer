# Conserved ligand-receptor axes in breast cancer

Analysis code for the article "Cross-cohort single-cell analysis identifies CCL5–ACKR1 and FN1–ITGA5/ITGB1 as ligand-receptor axes with opposing prognostic associations in the breast tumor microenvironment".

The whole analysis is one Quarto document, `analysis.qmd`. Its rendered version, `analysis.html`, describes every step and shows the code behind each table and figure. Download `analysis.html` and open it in a web browser to read it, or use the GitHub Pages link of this repository.

## Files

| File | Content |
|---|---|
| `analysis.qmd` | The analysis, as a Quarto document |
| `analysis.html` | The rendered analysis |
| `styles.css` | Style sheet for the rendered page |

## Data and software

All inputs are public. The section "Reproducing this analysis" of the page lists each data source with its accession, the expected layout of the `data/` folder, and the code that downloads the inputs. The section "Session information" lists the R packages and their versions.
